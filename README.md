# 🐍 Snake Game – React + TypeScript

A classic Snake game built with **React** and **TypeScript**, inspired by a coding challenge from **John Cricket**. This project helped me practice core front-end concepts including state management, rendering loops, and keyboard event handling.

---

## 🚀 Features

- Classic snake movement on a grid
- Collision detection (self + walls)
- Score tracking
- Responsive keyboard controls
- Clean TypeScript structure with React Hooks

---

## 🧱 Tech Stack

- ⚛️ React
- 🟦 TypeScript
